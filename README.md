# ci_cd_demo

A Flutter notes app with Firebase email/password authentication. Users register, log in, and manage personal notes stored in real time per-account in Cloud Firestore.

## Stack

- **Flutter** (Material 3) + **Dart** (^3.11.4)
- **GetX** — state management, dependency injection, and routing
- **Firebase Authentication** — email/password sign-up & login
- **Cloud Firestore** — per-user notes storage, real-time sync
- **GetStorage** — local persistence of the light/dark theme preference

## Project structure

```
lib/
  core/                 # shared constants, theme, utils, reusable widgets
  models/               # UserModel, NoteModel
  services/              # AuthService, FirestoreService, StorageService
  modules/               # one folder per feature/screen
    splash/  login/  register/  home/  note_form/  profile/  settings/
    <feature>/bindings/    -> registers the controller for that route
    <feature>/controllers/ -> state + business logic
    <feature>/views/       -> UI only
  routes/                # route names + GetPage table
  main.dart               # Firebase/service init, GetMaterialApp setup
  firebase_options.dart   # generated by FlutterFire CLI
firestore.rules           # per-user read/write security rules
```

Each feature module follows the same GetX pattern: a `View` (UI), a `Controller` (`GetxController` holding reactive state), and a `Binding` (wires the controller to its route). Cross-cutting services (`AuthService`, `FirestoreService`, `StorageService`) are registered once at app startup in `main.dart` rather than per-route.

## Data model

```
users/{uid}                    { name, email }
users/{uid}/notes/{noteId}     { title, description, createdAt, updatedAt }
```

Notes live in a subcollection under each user's own document, so Firestore security rules and queries never need to filter by a `uid` field.

For a full file-by-file breakdown of how everything works together, see [context.md](context.md).

## Getting started

```bash
flutter pub get
flutter run
```

Requires a configured Firebase project (`firebase_options.dart` + `google-services.json` / `GoogleService-Info.plist` per platform).
